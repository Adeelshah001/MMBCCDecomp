# Mega Man Battle Chip Challenge

This is a decompilation of Mega Man Battle Chip Challenge.

It builds the following ROM:

- **mmbcc.gba** `sha1: 72309736f3820470c6f372d6a05ad1f16bc5a946`

To set up the repository, see [INSTALL.md](INSTALL.md).

The original ROM is not included in this repository. You must supply your own legally obtained copy of the game (USA) as the base ROM for the build.
